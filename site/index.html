01

Cost is not a black box

Live cost per turn, hard budget caps and cache-hit visibility. An open-source harness earns nothing on token volume, so it has no reason to hide the meter.

02

Nothing changes unseen

Every write is previewed as a diff and confirmed before it is applied. Every shell command is shown before it runs. You stay the reviewer, not the cleanup crew.

03

Evidence instead of "done"

Runs end with what the harness observed - test exit codes, build output - not with an optimistic self-report. A claim is only as good as its proof.

04

Your keys stay yours

Anthropic, OpenAI or OpenRouter: one key each, stored in your OS keyring, never in a file. Prompt-cache accounting on every call.

GET STARTED

One binary.
Your provider key.

Requires Rust 1.88 or newer; there is no installer yet. On first run true-code asks for a provider and stores the key in your OS keyring.

Full install guide ↗ 
git clone https://github.com/philppplik/true-code
cd true-code
cargo install --path crates/tc-cli

truecode auth login openrouter  # or: anthropic, openai
truecode

That puts the truecode binary on your PATH. Keys can also come from the usual environment variables.

STRAIGHT ANSWERS

Good to know.

What is true-code?

An MIT-licensed, open-source agentic coding harness written in Rust. It drives coding models through a transparent agent loop with tools - read_file, glob, grep, patch, shell - and shows every step as it happens.

What do I need to start?

Rust 1.88+ to build, and an API key for Anthropic, OpenAI or OpenRouter. The key goes into your OS keyring on first run, or into the standard environment variables.

What works today, and what is planned?

Working in Phase P1: the agent loop with tools, diff preview and confirmation, budget caps, live cost per turn, cache accounting and evidence blocks. On the roadmap and not built yet: OS sandboxing, MCP and the LEARN mode that explains changes before applying them.

Is this website a running product?

No. This page explains the project. true-code is source you build and run locally; your code and your keys never touch this site.
